# HUJARILOVO

*FIGHT BEYOND LIMITS — рабочее название.*

![HUJARILOVO](brand/logo.webp)

Браузерная PvP-дуэль двух друзей в подпольной Яме. Каждый сход оба одновременно выбирают, **на какую линию уйти** и **в какую линию ударить**. Удар попадает, если пришёлся туда, где стоит соперник. Серии чтений, Накал пустых сходов, трескающийся пол, Финт и Досье привычек превращают простую угадайку в дуэль характеров и блефа. Бой до двух побед длится 3–6 минут.

## Как запустить

Нужен Node.js 20+.

```bash
npm install
npm run dev      # сервер :2567 + клиент :5173 с горячей перезагрузкой → http://localhost:5173
npm test         # тесты игровой логики (Vitest)
npm run build    # проверка типов + сборка клиента и сервера
npm start        # продакшен: один процесс раздаёт игру и WebSocket → http://localhost:2567
npm run sim -- 400 1   # бои ботов без графики: 400 боёв на пару, сид 1
python3 tools/build_art.py   # арт: art-source/*.png → client/public/art/*.webp (нужен Pillow)
```

Порт продакшен-сервера меняется переменной `PORT`, адрес — `HOST`.

## Как играть с другом
1. «Создать бой» → выбрать формат и время на сход.
2. «Поделиться» или «Копировать» — другу уходит ссылка вида `https://твой-сайт/?r=КОД`.
3. Друг открывает ссылку → «Принять вызов». Бой начинается сразу.
4. После боя — «Реванш». Счёт серии в комнате сохраняется.

Если обновить страницу посреди боя, игра вернёт на твоё место. Пока игрок не в сети, его сходы по таймеру играются повтором прошлого хода.

## Выкладка на Render

В корне лежит чертёж [`render.yaml`](render.yaml): один бесплатный веб-сервис во Франкфурте, Node 22, сборка `npm ci --include=dev && npm run build`, запуск `npm start`, проверка здоровья `/health`.

1. Войти на [dashboard.render.com](https://dashboard.render.com) и подключить GitHub-аккаунт с доступом к репозиторию `nvckmelx/combatpvp`.
2. **New → Blueprint** → выбрать репозиторий → **Apply**.
3. Через несколько минут игра будет доступна по адресу вида `https://hujarilovo.onrender.com` (точное имя Render покажет в карточке сервиса). Каждый пуш в `main` выкладывается автоматически.

Особенности бесплатного плана: после 15 минут без посетителей сервис засыпает, и первый вход открывается примерно за минуту. Комнаты хранятся в памяти, поэтому при засыпании или новой выкладке идущие бои обрываются.

На любом другом Node-хостинге всё то же самое: сборка `npm ci --include=dev && npm run build`, запуск `npm start`. Прокси перед сервером должен пропускать WebSocket на путь `/ws`.

## Что есть в игре
- **Экран боя с камерой из-за спины:** соперник лицом к тебе, твой боец спиной на переднем плане, HUD как в файтинге, выбор хода кнопками УХОД / УДАР внизу, кино-анимация схода. Арт — полный комплект по [`docs/art-brief.md`](docs/art-brief.md): три бойца по 15 поз, портреты, Яма, трещины, толпа, эффекты, экран VS и комикс-сплэш Сокрушения.
- **Выбор бойца:** Бородач, Лысый или Таксолог — только внешность, на числа не влияет.
- **Онлайн-бой 1v1 по ссылке или коду** без регистрации: до 2 или до 3 побед, таймер 6 / 8 / 12 с.
- **Все системы из концепции:** Накал, Серия и Сокрушение, Вкопался, Читаемый удар, Рывок, трещины и разбитые плиты, Финт с Контрой, Туман, Усталость, «Последний сход» при двойном нокауте.
- **Условия Ямы:** со второго раунда Яма меняет одно правило — Толпа ревёт, Тяжёлые кулаки, Мокрый пол, Дым, Гнилые плиты, Охота. Условие видно в Досье заранее.
- **Подсказки урона на линиях:** сколько нанесёшь и сколько получишь; НОКАУТ / ДОБЕЙ / НА ГРАНИ, когда раунд решает один удар; урон с Рывка и «читаемый» удар видно до выбора.
- **Досье между раундами и в конце боя** (привычки обоих), Индекс чтения, тепловая карта «уход × удар», счёт серии в комнате и Летопись против соперника в браузере.
- **Спарринг с ботами офлайн:** Центрист, Мститель, Упрямый, Чтец, Мастер Ямы, Хаос.
- **Управление:** тапы и мышь, с клавиатуры A/S/D — уход, J/K/L — удар, F — финт, пробел — готов, 1–4 — фразы.
- **Музыка и звук:** фоновая музыка меню и боя (27 % громкости, плавная смена), голос анонсера перед раундом, звуки ударов синтезируются в браузере. Одна кнопка выключает всё.
- **Эмоции** — одна за сход.

## Устройство

```
shared/   чистая логика без DOM и Node API: правила схода, бой, досье, боты, ведущий боя (фазы и таймеры)
  data/balance.json   все числа баланса
  test/               тесты Vitest, включая примеры из концепции
server/   Node.js + ws: комнаты по коду, авторитетный сервер, переподключение по токену, раздача клиента
client/   Vite + TypeScript без движка: DOM и SVG, экраны и арена; офлайн-спарринг гоняет shared прямо в браузере
tools/    sim.ts — симуляция боёв ботов
brand/    исходники бренда
docs/     концепция, брендинг, реестр ассетов
```

Сервер хранит выборы до схода и отдаёт каждому игроку только его вид (`PlayerView`). Линии зеркалятся под экран смотрящего, поэтому «лево» у каждого — своё.

## Баланс (npm run sim, 400 боёв на пару)
- Случайная игра против случайной: раунд ~9 сходов, попаданий 33 %.
- Читающий бот обыгрывает случайную игру в ~70 % боёв: системы вознаграждают чтение, а не удачу.
- Мастер Ямы (думает на этаж выше) обыгрывает Чтеца в ~77 % боёв.
- При любом условии Ямы раунд длится 7–8 сходов, а Чтец выигрывает у случайной игры 59–68 % боёв.
