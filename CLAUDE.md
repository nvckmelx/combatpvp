# HUJARILOVO — правила проекта для Claude

HUJARILOVO — рабочее (тестовое) название. Браузерная PvP-дуэль 1v1 для двух друзей: каждый сход оба одновременно выбирают уход (Л/Ц/П) и удар (Л/Ц/П).
Полный дизайн — `docs/concept.md`, бренд — `docs/branding.md`. Это отдельная игра, не связанная с Millstorm.

## Стек (не менять без обсуждения)
- TypeScript (strict) везде, npm workspaces: `shared/`, `server/`, `client/`, скрипты в `tools/`.
- `shared/` — чистая логика: правила схода, бой, досье, боты, ведущий боя (`BoutHost`). Без DOM и Node API; таймеры передаются через `Scheduler`.
- `server/` — Node.js + `ws`. Сервер авторитетный: выбор соперника не уходит на клиент до схода.
- `client/` — Vite + TypeScript, DOM и SVG без игрового движка. Клиент шлёт только команды (choose / rematch / skip / emote / leave). Исключение — офлайн-спарринг: он запускает `BoutHost` из `shared/` прямо в браузере.
- Тесты: Vitest для `shared/`.

## Принципы
1. Ядро неизменно: два одновременных выбора за сход, три варианта каждый. Новые системы меняют цену решений, а не добавляют кнопок.
2. Все числа баланса — в `shared/data/balance.json`, не в коде (клиент тоже берёт их оттуда).
3. В логике линии абсолютные (со стороны бойца 0); всё, что уходит игроку, зеркалится под его экран в `BoutHost.view`.
4. Расчёт схода (`shared/src/rules.ts`) — чистая детерминированная функция; порядок — `docs/concept.md`, раздел 5.4. Случайность — только через `createRng(seed)`.
5. После каждой задачи должны проходить `npm test` и `npm run build`; при изменении баланса — прогнать `npm run sim`.

## Оригинальность
- Никаких ассетов, названий и текстов из других игр; персонажи — только оригинальные.
- Каждый внешний ассет записывается в `docs/assets-registry.md` (файл → источник → лицензия).

## Брендинг
- Палитра, шрифты и логотип — `docs/branding.md`, исходники — `brand/`, копии для игры — `client/public/brand/`.
- На арене «ты» всегда красный, соперник — стальной.

## Команды
- `npm install` — установка
- `npm run dev` — сервер (порт 2567) + клиент (порт 5173)
- `npm test` — тесты shared
- `npm run build` — проверка типов и сборка
- `npm start` — продакшен-сервер с собранным клиентом
- `npm run sim -- 400 1` — бои ботов без графики
